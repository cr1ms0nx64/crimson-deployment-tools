Crimson Native Deployer WPF v21

Start:
1. Ordner vollständig entpacken.
2. Crimson Native Deployer.exe starten.
3. ZIP per Drag and Drop oder über ZIP wählen hinzufügen.
4. Zielserver wählen und Deploy starten.

Crimson Deploy Tool 1.0.0 Testplan

1. Start und Update
App starten, Version 1.0.0 in der Sidebar prüfen, Fenstertitel muss Crimson Deploy Tool lauten.
Update Paket von 0.53.0 auf 1.0.0 installieren und prüfen, dass config, logs und backups erhalten bleiben.

2. Server und Online Status
Hub und ACP Server Cards prüfen.
Online Status prüfen ausführen.
server-health.json prüfen.
Badges und Dots müssen nach dem Check sichtbar wechseln.

3. ZIP Erkennung
crimson-hub-1.0.0.zip wählen und automatische Hub Auswahl prüfen.
crimson-acp-1.0.0.zip wählen und automatische ACP Auswahl prüfen.
crimson-acp-0.2.8-irgendein-suffix.zip wählen und ACP Auswahl prüfen.
Falsche Server Kombination testen und Blockade oder Warnung prüfen.

4. Preflight
Preflight ohne ZIP testen.
Preflight mit gültiger Hub ZIP testen.
Preflight mit gültiger ACP ZIP testen.
Private Key kurz auf falschen Pfad setzen und Fehlermeldung prüfen.

5. Deploy
ACP Paket deployen.
Hub Paket deployen.
Nach Erfolg prüfen, ob config/deploy-state.json sofort aktualisiert wird.
App schließen und neu starten.
Gespeicherte Versionen müssen erhalten bleiben.

6. Lokale Backups
Einstellungen öffnen.
Backup Ordner setzen.
Backup jetzt erstellen klicken.
ZIP Inhalt prüfen: config/servers.json, config/deploy-state.json, config/app-settings.json, config/server-health.json, logs/deploy-history.json, logs/deploy-state.json.
Automatisches Config Backup nach Deploy aktivieren und nach Deploy prüfen.

7. Rollback
Rollback Fenster öffnen.
Cards prüfen.
Rollback auf ältere Version auswählen.
Warnung prüfen.
Rollback starten.
Nach Erfolg deploy-state.json und Server Card prüfen.

8. Verlauf und Support Paket
Deploy Verlauf öffnen.
Cards müssen sichtbar sein.
Support Paket erstellen.
ZIP öffnen und prüfen, dass keine Secret Keys, Tokens oder Private Key Inhalte enthalten sind.

9. Livefeed
Log ein und ausklappen.
Fehler rot, Warnungen amber, SSH und SCP cyan, OK grün prüfen.
Permissions Policy und TCP Vorprüfung dürfen Deploy nicht unnötig rot oder blockierend machen.

10. Subwindows
Server verwalten, Einstellungen, Rollback und Deploy Verlauf öffnen.
Crimson Icon, dunkle Titlebar und dunkle Controls prüfen.
